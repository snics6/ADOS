1. **ADOS の採点は基本的にセッション全体**に基づく。課題は行動を引き出す *press* であり、「その課題だけで項目を採点する」わけではない。

## 課題ごとの主 press（要約）

公開二次資料で繰り返し述べられる各課題の観察目的：

| 課題 | 主たる観察目的（要約） |
|------|------------------------|
| 構成課題 | 必要なものを**要求**する仕方（言語・指差し・身振り） |
| 呼名反応 | **名前呼びへの反応**（視線を向けること） |
| ごっこ遊び | 象徴的遊び、一連の行為、人形への見立て |
| 共同遊び | 相互的なやりとり、対人的働きかけ・反応・ラポール |
| 会話 | やりとり会話、視線・表情・韻律・身振りの統合 |
| 共同注意への反応 | 検査者の視線・指差しへの**共同注意反応** |
| 実演課題 | 身振り・身体による行為の**表象**（叙述的身振り） |
| 絵の叙述 | 絵を見ながらの言語・指差し・身振り |
| 本のストーリー | 物語叙述、指差し、共同注意的な共有 |
| 自由遊び | 非構造下の遊び・自発的働きかけ・反復行動の出やすさ |
| 誕生日パーティ | 機能的／象徴的遊び、スクリプト、喜びの共有、見せる |
| おやつ | 要求、共有・提供、なじみの状況での対人やりとり |
| ルーティン期待 | ルーティンへの期待、喜びの共有、要求 |
| しゃぼん玉 | 要求、**共同注意の自発的開始**、喜びの共有 |
