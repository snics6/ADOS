## 残っている確認事項

リポジトリの中を読んでも判断できないものだけを挙げる．**分からないものは「分からない」と返してほしい．
論文側では，返ってこなかった項目は主張を弱めたまま残す．**

### 1. ルーティン課題の3,190秒（53分）★

補足表S1の外れ値．ルーティンの最大が3,190秒，実演の最大が1,115秒で，中央値は数分以下である．
3,190秒は ADOS-2 実施1回分の標準所要時間に匹敵する．
分割ミスか，実施が長引いたのか，録画に ADOS 以外の場面が入っているのか．

活動分割は本論文の独立変数そのものなので，ここが壊れていると中核主張が崩れる．

### 2. 4活動を解析しなかった理由

`CANONICAL_TASK_IDS = range(1, 11)` で10活動に固定されている．
プロトコルの 2.呼名反応／4.共同で遊ぶ相互的な遊び／5.会話／14.しゃぼん玉遊び が対象外である．
実施しなかったのか，実施したが分割できなかったのか，短すぎたのか．

### 3. 言語水準

年齢は取得できたが，言語水準の指標がラベル表に見当たらない．
発話量の関連を発達水準と分離するのに必要である．無ければ「無い」で構わない．

### 4. SA CSS / RRB CSS が算出可能か

現在は**生のドメイン合計**を目的変数にしている．`hus2014domaincss` は較正済みドメイン得点のほうが
子どもの特性の影響を受けにくいとしており，論文はその文献を引きながら生の合計を使っている状態である．

### 5. 特徴が未定義になる機構

検定に入る n が特徴によって 42〜59 と変動する．また**実験1と実験2で同一セル・同一特徴の n が
食い違うセルが41中8ある**．族ごとに「どういう条件で未定義になるか」を教えてほしい．

### 6. 日本語版 ADOS-2 を使ったか

Methods で「日本語版を用いた」と書き `lord2015ados2jp` を引いている．
ラベル表の項目名が日本語なので使ったと推測されるが，事実確認が取れていない．
