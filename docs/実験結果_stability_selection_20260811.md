# 安定性選択（方法1）結果

参加者レベル 80% サブサンプル × 200 回。各回で Stage1（4 手法）と Notable 選定を最初からやり直し、セルの選定頻度を記録。

- スクリプト: `scripts/run_stability_selection.py`
- 出力: `outputs/experiment/stability_selection/`
- 設定: n_participants=63 → 各回 50 人、`cv_repeat_scale=0.5`（計算量のため CV 繰り返し半分；選定規則は Stage1 と同じ）
- `freq` = 選定回数 / 200（非適格回は「非選定」）
- `freq_given_eligible` = 選定回数 / 適格回数

## 要約

| 実験 | セル数 | freq≥0.5 | freq≥0.8 |
|---|---:|---:|---:|
| A 項目 | 737 | **4** | **2** |
| B 集計 | 295 | **20** | **3** |

- A では安定に残るセルはごく少ない（共同注意 dyad×B-11、実演 examiner×A-2 が freq≥0.8）。
- B では **本のストーリーの説明が支配的**で、freq≥0.8 の 3 セルはすべて story×child。
- 予想「小 n の story は頻度が低い」は **A の絶対頻度では一部当てはまるが、適格条件付きでは高く、B では逆に最安定**。

Spearman(n, freq): A ρ=−0.43、B ρ=−0.39（小 n ほど top-K に入りやすい傾向）。一方、以前の n vs Stage1 AUC は負相関なし → **「平均スコアが上がる」のではなく「選定手続きが小 n の上側尾を拾う」**ことが安定性指標で見える。

## 解釈（方法論メモとの対応）

1. **Stage1/Stage2 が同一データ上の実質1検定である**点は、安定性選択の結果でも裏付けられる — 1回の Stage2 で p<0.05 だったセルの多くは、リサンプリング選定で低頻度に落ちる（特に A）。
2. **story を「小 n ゆえ不安定」と期待した予測は、B では支持されない。** 適格なサブサンプルではほぼ毎回 top に入る → 見かけの高さは「1回の上振れ」だけでは説明しにくく、課題固有の構造（または検出可能参加者の安定した偏り）を疑う余地が大きい。
3. 次の手: 方法2（最大値統計量の並べ替え）で「737/295 から最良を取る」家族単位誤差を直接評価する。
