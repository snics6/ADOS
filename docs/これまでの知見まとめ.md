## 1. 研究上の位置づけ（変わっていない前提）

- 新規性は「ADOS の課題が異質」自体ではなく、**既存自動評価が課題プールを前提にしてきた代償を定量化したこと**、および **項目×課題×情報源の対応構造を可視化したこと**にある。
- 外部臨床診断を正解にした分類は設計原則として避ける。`Diagnosis` は ADOS 内部アルゴリズムの分類のみを用いる。
- 小標本（セル n≈16〜55）では、多特徴・多重比較・ネストCVのリークが結果を容易に歪める。

## 2. 第1世代（マトリクス / Phase）で分かったこと

詳細: `old_files/README.md`、`docs/old/検証ログ.md`、`docs/old/議論まとめ_実験手順書.md`

**維持してよい主張の方向**
- **課題をまたぐプールは一様に良いわけではない**（1-1a: 実測 pooled はランダムプールより良くない；1-1c: 課題ペアで性能が大きく変動）。
- **課題相性は項目依存**（Aff-3: 項目間の affinity 相関は弱く、符号逆転が多い）。
- 群平均除去後も pooled&lt;single の劣化パターンは残る（1-6）。検出課題数と SA の関連は弱い〜中程度で、MNAR の強い偏りは少なくとも v1 では支持されにくい（1-7）。

**弱さ・失敗として残るもの**
- **情報源プロファイルの半分割再現性はほぼゼロ**（0-b fail）。「どの情報源が効くか」のマップは、このコホートでは安定に再現しなかった。
- 探索セル数が数百〜千規模だと、点推定の上位は偶然と選抜バイアスを含みやすい。
- v2（品質マスク入り特徴の作り直し）は Phase 3 以降未完了。学習未収束セルが混ざる問題もログ上で確認済み。

**第1世代の道具立て（現行とは一部違う）**
- LOPO の OOF 予測ペアに対するブートストラップ CI
- パーミュテーション p ＋ FDR（BH）
- 群内（within）解析
- Ridge は当時 `α=10.0` 固定（ネストCVしない）

現行の実験2は LOPO の `sign(ρ)×x`．実験3は交差標本の ρ の差．補助の Ridge と旧い移植・プールは学習側だけで標準化し，RidgeCV が α を選ぶ．体の大きさの補正はかけない．

## 3. 第2世代（ados_seg / 動態・確証）で分かったこと

詳細の原本はすべて `docs/old/` と `old_files/02_ados_seg_202608/`。

### 3.1 特徴量まわりの技術的教訓

- **課題横断 ICC で特徴を捨てるのは誤り**。ADOS 課題は異質な行動を引き出す設計なので、課題主効果を誤差に算入すると姿勢系などを誤って捨てる。
- **絶対 yaw は座席／カメラ配置を測りやすい**。二人の和の分散が小さく、個人差に見えていたものの多くが配置由来。速度・RMS・角度変化系はオフセット不変でこの交絡を避けやすい。
- **MAR（口縦横比）は横向きで見かけ上膨らむ**。yaw との交絡が大きく、調整なしでは信頼性が高く見えて中身が方位だった。
- セグメント分割（20秒）で参加者×課題交互作用と測定誤差を分けようとしたが、ゲートウェイ段階では **n≈56 でセル単位確証は検出力不足**（真の AUC 0.70〜0.80 でも検出困難）と判明。
- 動態特徴（頭部運動・身体・同期・会話時間構造）へ作り直し。Koehler et al. の BAC≈63% が現実的な参照天井の一つ。音声波形がないため F0 系は不可。

### 3.2 課題別・事前登録確証（2026-08-07）

- 事前登録した補正を通過したセルは **168 中 0**。
- 連続指標（SA・RRB・SUM・CSS）は完全帰無。Diagnosis も帰無中央以下。
- 2値項目に境界線上の兆候はあるが、主張として成立する水準ではない。
- **「見つからなかった」結果**として記録する（検出力不足と真の弱さの切り分けは限定的）。

### 3.3 within-fold 特徴選択 → 安定性選択

- Stage1 で上位を取り Stage2 で並べ替えると、一見 p&lt;0.05 の候補が多く出るが、**同一データ上の実質1検定＋選抜バイアス**を含む。
- 参加者 80% サブサンプル×200 回の安定性選択では、項目側で freq≥0.8 はごく少数。集計側では **story×child が支配的**に見える。
- n と選定頻度は負相関（小 n ほど top-K に入りやすい）。点推定 AUC の高さとは別種のバイアス。
- story の高頻度は「1回の上振れ」だけでは説明しにくい一方、**特定参加者（重症寄り数名）の除外と top-K 脱落が結びつく**。コホート内で stable でも generalizable とは言えない。言語水準 A-1 との単純相関では説明されなかった。

### 3.4 第2世代からの設計上の帰結（→ 第3世代、その後第4世代）

- 数百セルの探索＋情報源分割は、多重比較と選抜バイアスで論文の柱にしにくい。
- 第3世代は、**目的変数を集約指標に絞り、情報源を1モデルに統合し、セル数を ≈44 に落とす**方針だった。
- 性能推定は Ridge、重要度は Elastic Net、固定 Top-k ではなく偶然水準比較、という切り分け。
- 第3世代の本線（fold-safe B、課題2つの平均、α/β/γ）は、方向は見えても **FDR 0本**が続いた。第4世代は袋の切り方を変えた（現行手順書 §2）。

## 5. 先行研究メモ（捨てない要点）

詳細レビューは `references/discussion.md` および `references/papers/`。

- 課題分割の先例はあるが、項目×課題×情報源の同時マッピングは乏しい（Ali / Natraj / Bone / Koehler 等の限界の整理は議論まとめに記載）。
- 発話率・ターンテイキングによる SA 推定、音響 CNN による SA/RRB 推定など、セッション全体プール前提の報告値は比較対象になるが、本研究のセル定義とは直接一致しない。
- 検査者も相互作用の当事者である、という Bone らの視点は、examiner / dyad 特徴を残す理由の一つ。
