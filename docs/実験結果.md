# 実験結果まとめ（実験1〜3）

対象コホート：ADOS-2 Module 2，59人（`configs/cohorts/features_63.yaml`）．
検証日：2026-09-04〜05．特徴量は再抽出後（`outputs/features/`，2026-09-04時点）の値で，実験1〜3を通しで再実行し，数値の再現性を確認したうえでの結果である．

このドキュメントは，統計の専門知識を前提とせずに読めるように，各実験について「何を確かめたかったか」「どうやって確かめたか」「結果は何だったか」「結果は何を意味するか」の順に説明する．

## 0. 全体像

このプロジェクトは，ADOSビデオから抽出した行動特徴（発話量，ジェスチャー，動き，やり取りの構造など）が，ADOSの重症度スコア（SA：対人的感情，RRB：限定的・反復的行動，CSS：比較スコア）とどう関係するかを調べるものである．3つの実験は，互いに独立ではなく，前の実験の結果を次の実験で確認・検討する関係にある．

| 実験 | 一言でいうと | 使う人数の分け方 |
|---|---|---|
| 実験1 | どの行動特徴がどの課題でスコアと関係しているかを見つける | 分けない（59人全員） |
| 実験2 | 実験1で見つかった関係が，1人抜き交差検証でも成り立つか確認する | 1人抜き（LOPO） |
| 実験3 | 同じ名前の特徴を複数の課題にまたがって平均する（プールする）と，関係は強まるか弱まるか | 分けない（課題間の比較） |

以下，実験ごとに詳しく述べる．

## 1. 実験1：個別特徴の発見（`run_exp1_univariate.py`）

### 1-1. 何を確かめたかったか

59人ぶんのデータの中で，「ある課題である行動特徴を測ると，その値がADOSの重症度スコアと関係している」と言えそうな組み合わせを，偶然ではないと言える水準まで絞り込んで発見すること．これは**探索的な発見フェーズ**であり，「未知の子どもに使えるか」はまだ確認しない．

### 1-2. どうやって確かめたか

課題（10種類）×得点（SA・RRB・CSS）×情報源（子ども／検査者／ペア）ごとに，多数の候補特徴（合計124候補）について，次の3段階でふるいにかけた．

1. **閾値づくり**：重症度のラベルをでたらめにシャッフルした「何も関係がないはずの状態」を50回作り，そのたびにコホートを半分に割って相関の符号が一致する頻度（安定度）を200回のブートストラップで計算する．この「デタラメな状態での安定度」の95パーセンタイル点を閾値τとする．
2. **Stage A（候補選定）**：シャッフルなしの実データで同じ安定度を計算し，τを超えた特徴だけを候補として残す．「偶然でもこのくらいは起きる」という基準線を超えているかのチェック．
3. **Stage B（本検定とFDR補正）**：候補について改めて置換検定（1000回）でp値を出し，同じ課題×得点の中でBenjamini-Hochberg法により多重比較補正（FDR）をかける．補正後のq値が0.05未満のものを「当たり」とする．

### 1-3. 結果

候補2010件のうちStage Aを通過したのが124件，最終的にFDRを通過した「当たり」は**98件**（q<0.05）．

| 得点 | 当たり数 |
|---|---|
| SA | 46 |
| CSS | 34 |
| RRB | 18 |

| 情報源 | 当たり数 |
|---|---|
| child（子ども） | 39 |
| examiner（検査者） | 36 |
| dyad（ペア） | 23 |

10課題すべてで当たりが見つかった（併合規則の修正前は「絵の説明」だけがゼロだったが，
区間から別課題の時間が抜けたことで3件出るようになった）．

代表的な当たり（q値が特に小さいもの）：

| 課題 | 得点 | 情報源 | 特徴 | ρ | 意味 |
|---|---|---|---|---:|---|
| 自由遊び | SA | examiner | txt_examiner_n_utt（検査者の発話数） | −0.444 | 検査者がよく話すほどSAは低い（軽い） |
| 実演 | RRB | examiner | examiner_turn_words_mean（検査者の1発話あたり語数） | −0.429 | 検査者が長く話すほどRRBは低い |
| 自由遊び | SA | dyad | rsp_n_exam_turns（検査者のターン数） | −0.409 | 検査者のやり取りが多いほどSAは低い |
| 本のストーリーの説明 | SA | examiner | txt_examiner_n_utt | −0.401 | 同上の傾向が別課題でも出ている |

（全98件は`outputs/exp1/hits_main.csv`に一覧がある．）

### 1-4. 結果の意味

- 特定の行動特徴と重症度の間に，偶然では説明しにくい相関が複数見つかった．特に「検査者がよく話す・長く話す」課題ほどSAスコアが低い（症状が軽い）という傾向が，自由遊び・本のストーリーの説明など複数の課題で共通して見られる．
- ただしこれは**59人全員を使った一発の分析**であり，「新しい子どもにも使える予測式」ではない．そこを確認するのが実験2である．
- 課題5（絵の説明）に当たりがないことも，「この課題は今回の特徴セットでは重症度と関係する情報を引き出せていない」という否定的な情報として記録に値する．

## 2. 実験2：LOPO確認（本線・補助の2本立て）

### 2-1. 何を確かめたかったか

実験1で見つかった「当たり」が，**1人を除いた残りの人だけを見て予測モデルを作り，その除いた1人を当てられるか**（Leave-One-Participant-Out，LOPO）という，より厳しい条件でも成り立つかどうかを確認すること．全員を使った実験1だけでは「たまたま全体に強く出ただけ」の可能性が排除できないため，これを確認する．

2つの手法を用意した．**本線**（毎回選び直す，厳しい方）と**補助**（固定して選び直さない，甘い方）で，あえて対比させている．

### 2-2. 本線：LOPO, sign(ρ)·x（`run_exp2.py`）

**方法**：課題×情報源×得点の組み合わせのうち，実験1で当たりが出た41通り（セル）それぞれについて，

1. そのセルの情報源に属する全候補特徴をプールする（実験1の当たり特徴だけでなく，同じ情報源の特徴すべて．平均13〜27本）
2. 1人抜き（LOPO）の各回で，**除外した本人を含まない残り58人だけ**を見て，プール内の候補の安定度を計算し，閾値τを超えるものの中から最良の1本を選ぶ
3. その特徴の相関の符号（プラスかマイナスか）を，除外した本人の値に掛けて予測値とする
4. 全員ぶんの予測値と実際のスコアの相関ρを計算し，被験者単位のシャッフルによる置換検定（200回）でp値を出し，46セル全体でFDR補正する

**結果**：FDRを通過したのは**46セル中2セル**．

| 課題 | 情報源 | 得点 | n | 使われた特徴 | ρ | p | q |
|---|---|---|---:|---|---:|---:|---:|
| 自由遊び | examiner | SA | 58 | txt_examiner_n_utt | 0.444 | 0.020 | 0.030 |
| 自由遊び | dyad | SA | 58 | rsp_n_exam_turns | 0.409 | 0.020 | 0.030 |
| 全46セル平均 | | | | | 0.287（中央値0.312） | | |

**意味**：実験1で見つかった98件の当たりのうち，「1人抜きでも予測に使える」水準まで生き残ったのは2件だけだった．これは「実験1の当たりの多くは，全体を見て相関を計算する分には確かに存在するが，個人単位の予測に使えるほど頑健ではない」ことを意味する．研究として悲観的に見える数字だが，**これは正直な答えであり，実験1だけでは分からなかった限界を明らかにできたという点で意味がある**．生き残った2件はどちらも**自由遊びでの検査者の発話量とSAの関係**（発話数とターン数という2通りの測り方）であり，本線という厳しい条件を通過した，相対的に信頼できる知見と言える．どちらも活動長を統制しても符号が残る（Δρ 0.040・0.042）．

### 2-3. 補助：Exp1の当たりをそのままRidge（`run_exp2_ridge.py`）

**方法**：本線と違い，実験1で当たりになった特徴列（1〜2本，全59人で決めた固定リスト）を**そのまま**使い，LOPOの各回ではその固定の列でRidge回帰を学習・予測するだけで，列の選び直しはしない．

**結果**：FDRを通過したのは**46セル中38セル**．

**意味**：本線との差（2/41 対 37/41）は，**「予測に使う特徴を，テスト対象者を除いた分だけで選び直すかどうか」がどれだけ結果を左右するか**を明確に示す実例である．補助の方法では，どの特徴を使うかという最も重要な選択が「テスト対象者を含む全員」を見て決められているため，見かけの性能が甘く出る．この補助スクリプトは，最初から「本線ではない」対照実験として設計・運用されており，この落差自体が研究上の教訓（特徴選択のリークがどれだけ結果を歪めるかの実例）になっている．

### 2-4. 実験2全体の結論

- 実験1の当たり98件のうち，1人抜きの厳しい条件で確認できたのは2件のみ．
- 「特徴選択をどこでやるか」（テスト対象者を含めるか除くか）で結果が劇的に変わることが，本線と補助の対比で定量的に示された．
- 生き残った2件は，いずれも「検査者の発話量」と「SAスコア」の関係であり，複数の課題（自由遊び・おやつ）で一貫している．

## 3. 実験3：課題間の異質性（`run_hetero.py` → `run_exp3_findings.py`）

### 3-1. 何を確かめたかったか

多くの自動評価研究は，課題を区別せず，同じ名前の行動特徴（例：発話の割合）を複数の課題で平均して1本の数値にする（これを「プール」と呼ぶ）．実験3の問いは：**同じ名前の特徴を課題どうしで平均すると，重症度との関係は強くなるのか弱くなるのか．弱くなるなら，それは測定誤差（ノイズ）のせいか，課題そのものが違う行動を引き出しているせいか．**

### 3-2. 使う道具（統計の基礎）

- **Spearman相関ρ**：2つの数値列を「順位」に直してから相関を取ったもの．−1（完全に逆向き）〜+1（完全に同じ向き）の範囲で，「一緒に動く度合い」を表す．
- **r**：課題Aでのある特徴の値と，課題Bでの同じ特徴の値どうしのρ（重症度は使わない）．「同じ子どもが2つの課題で似た順位になるか」だけを見る．
- **プール後の相関ρ_z**：課題Aと課題Bの順位を平均してから重症度との相関を取ったもの．次の恒等式で決まる（データに当てはめた式ではなく，平均の定義から数学的に導かれる式）．

```
            ρ_A + ρ_B
ρ_z = ───────────────────
         √( 2 × (1+r) )
```

- **λとλ\***：2課題のうち強い方をA，弱い方をBとして`λ=ρ_B/ρ_A`．プールが「強い方だけ使うより得」になる境界が`λ*(r)=√(2(1+r))−1`．rが高い（2課題が似ている）ほど，Bにより強い信号が必要になる．

### 3-3. やったこと（要約）

1. **全対のr**：67特徴×45課題ペア＝3015組すべてで，重症度を使わずrだけを計算（選択バイアスを避けるため，実験1の結果を見ずに全部計算）．
2. **式の検算**：符号が逆だった10組で，実測ρ_zと数式から予測したρ_zを比較し，ほぼ完全一致（差の中央値0.0002）を確認．コードが数式通り正しく動いていることの裏付け．
3. **21対の記述**：実験1で複数課題の当たりになった特徴について，差が最大の課題ペアを21組抽出し，ρの値と信頼区間（人を復元抽出するブートストラップで作成）を記述．p値は事後選択バイアスがあるため結論には使わない．
4. **符号逆転の構造分析**：会話を「4回以上続く連鎖」に分け，「検査者が話しかけて始めた」か「子どもが自分から始めた」かで分けて再計算．
5. **課題の長さの影響確認**：課題の長さ（秒数）の影響を統計的に除いても符号逆転が残るかを確認（偏相関）．
6. **参考集計（結論には使わない）**：あえて計算し，あえて使わない理由まで明記した集計．

### 3-4. 結果

**(1) 同じ名前の特徴でも，課題が変わると並びはあまり一致しない**
3015組のrの中央値は**0.24**（四分位9〜40%）．r<0.2が42%，r<0（逆向き）が13%．この水準では，λ*(0.24)≈0.58——弱い方の課題が強い方の相関の約58%を残していないと，プールは損になる．

**(2) 符号が逆になる組が実際に存在する**
実験1の当たりから切った21対のうち，**8対はρ_AとρBの符号が逆**だった．例：長いやり取り連鎖の頻度とSAの関係で，共同注意ではρ=+0.34，自由遊びではρ=−0.24．それぞれの課題単独では重症度と関係しているのに，プールするとρ_z≈0.06（信頼区間は0を含む）まで消えてしまう．測定誤差だけではこの符号逆転は説明できないため，少なくとも一部は「課題が別のものを引き出している」ことを示す証拠である．

**(3) 平均しても精度は上がらない**
反転していた10組の95%信頼区間を見ると，強い方の課題単独では10組中7組で信頼区間が0を含まない（信号あり）のに，プールした後は**10組中10組すべてで信頼区間が0を含む**．区間の幅も単独0.51に対しプール0.55と，むしろ広がっている．

**(4) 符号逆転は「検査者が話しかけて始めたやり取り」に集中**

| | 共同注意 | 自由遊び |
|---|---|---|
| 検査者開始 | +0.36（区間0を含まない） | −0.37（区間0を含まない） |
| 子ども開始 | +0.13（区間0を含む） | −0.15（区間0を含む） |

子ども開始の連鎖はどちらの課題でもほぼ無関係．逆転は検査者からの働きかけへの応じ方という，課題ごとに意味が変わりうる側面に絞り込まれた．

**(5) 課題の長さでは説明できない**
長さの影響を統計的に除いても，16組中16組で符号逆転がそのまま残った．

### 3-5. 結果の意味（書いてよいこと／書いてはいけないこと）

**書いてよいこと**：
- 同じ名前の特徴の課題間rの中央値は0.24であり，弱い課題が強い課題の相関の約58%を残していない限り，プールは損である．
- 符号が逆になる組が実際に存在し，測定誤差だけでは説明がつかない．その逆転は検査者主導のやり取りに構造がある．
- 平均しても信頼区間は狭まらず，推定値の位置だけが0に近づく．

**書いてはいけないこと**：
- 「行動特徴は一般に課題依存である」という一般論（今回確認したのはこのデータでの具体例のみ）
- 「プールは常に有害である」（同じ向きでrが低ければ得になる場合もある）
- 「反転8対が検定を通った」ことを主結果にする（21対の切り出し自体が事後的なため，p値は参考情報止まり）

## 4. 全体を通じた結論

1. **実験1**は，ADOS行動特徴と重症度スコアの間に，偶然では説明しにくい相関を98件発見した．
2. **実験2**は，そのうち1人抜き交差検証という厳しい条件で生き残ったのはわずか2件だと明らかにした．同時に，「特徴選択をどこでやるか」が結果をどれほど左右するかを，本線と補助の対比によって定量的に示した．
3. **実験3**は，実験1・2で扱った「1課題＝1数値」という前提そのものを検証し，同じ名前の特徴を課題間で平均する（プールする）操作が，多くの場合で関係を弱め，場合によっては符号ごと打ち消してしまうことを示した．これは，課題を区別せずセッション全体で1つの数値にまとめる一般的な自動評価アプローチに対する警鐘であり，同時に「なぜ実験1の当たりが課題ごとにバラバラな特徴になっているか」を裏付ける知見でもある．

3つの実験は，「発見（実験1）→厳しい確認（実験2）→前提の検証（実験3）」という一貫した流れで，行動特徴とADOSスコアの関係についての知見を積み上げている．

## 5. 再現性についての付記

実験1・2・3のいずれについても，2026-09-04〜05に実施したフル再実行によって，現行コード・現行の抽出済み特徴量で上記の数値が再現することを確認済みである（詳細は各実験のコード実行ログおよび`outputs/`配下の生成物を参照）．乱数を使う箇所（ブートストラップ・置換検定）はすべて固定シードで決定的に計算されており，`run_hetero.py`本体と`run_exp3_findings.py`単体を独立に実行して全数値が完全一致することも確認済みである．
