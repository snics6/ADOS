# Within-fold 実験 A / B 結果まとめ

探索的な within-fold 特徴選択パイプラインの Stage2（ラベル並べ替え 1000 回）結果。
セルは Stage1 スコアで自動選定した候補であり、p 値には選定バイアスがある。確定発見ではなく次の確認実験の候補リストとして扱う。

共通設定:

- 特徴: `dyn_v1` 課題レベル動態（ScaleAdjuster 後）。child/examiner 各 13、dyad 8。
- 課題: 11 課題（呼名〜本のストーリーの説明まで）。
- 手法（Stage1）: `ridge_all` / `selectk_ridge_1` / `selectk_ridge_2` / `lasso`。セルごとに最良手法を 1 つ採用。
- CV: 課題別 repeated stratified（多くは 5×10；呼名 2×20、絵の叙述 3×15）。
- 帰無中央・帰無95%: 並べ替え帰無分布における **主指標**（分類=AUC、連続=Pearson r）の中央値と 95 パーセンタイル。
- スクリプト: `scripts/run_within_fold_items.py` / `scripts/run_within_fold_aggregates.py`
- 出力: `outputs/experiment/within_fold_items/` / `outputs/experiment/within_fold_aggregates/`

## A. 項目スコア（二値）

### 実験内容

- **目的**: 課題×出所（child / examiner / dyad）×ADOS 項目から、動態特徴で項目異常の有無を予測できるか。
- **目的変数**: 23 項目を二値化（0 vs >0；コード 8 は欠損）。
- **Stage1**: 全 usable セル（737）×4 手法を AUC で評価（並べ替えなし）。
- **Notable**: セルごとに最良手法の AUC で、AUC≥0.65 を優先し上位 **20** セルを Stage2 へ。
- **Stage2**: 1000 ラベル並べ替え。主指標は AUC。
- **結果要約**: Stage2 20 セル中 p<0.05 は **17**。

## B. 集計スコア + Diagnosis

### 実験内容

- **目的**: 同じ特徴・課題・出所枠で、SA / RRB / SUM / CSS（連続・二値）と Diagnosis を予測できるか。
- **目的変数**:
  - 連続: SA, RRB, SUM, CSS → 主指標 **r**（参考に CCC）。
  - 二値: SA>7, RRB>0, SUM>7, CSS≥4, Diagnosis（Non-ASD 以外）→ 主指標 **AUC**。
- **Stage1**: usable セルを 4 手法で評価。
- **Notable**: 連続は r≥0.25 の上位 **15**、二値/Diagnosis は AUC≥0.65 の上位 **15**（計 30）。
- **Stage2**: 1000 ラベル並べ替え。
- **結果要約**: Stage2 30 セル中 p<0.05 は **26**。
