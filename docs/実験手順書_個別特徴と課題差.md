## 0. 何を主張し、何をしないか

ADOS-2 Module 2 の1回は、構成、ごっこ、共同注意、実演、絵、本、自由遊び、誕生日、おやつ、ルーティンの **10課題** に分かれる。同じ子でも、課題が変わると話し方と動き方が変わる。自動評価の多くは、課題を潰してセッション全体で1本の特徴を出す。

**3段**

1. **実験1**: 特徴を1本ずつ見る。課題×得点ごとに、半分割りで安定し、点数の名札を入れ替えても残る列の名簿を作る。探索である。
2. **実験2**: 実験1で当たりがあった課題×情報源×得点について、学習側だけで1本選び、外した1人の点数が読めるかを見る。同一の59人での校正である。
3. **実験3**: 同名特徴の課題間の順位相関 \(r\)、2課題平均の式、符号が逆になる例。検定はしない。

**しないこと**

- 外部診断（ASD か否か）を主軸にしない。見る点数は SA / RRB / CSS だけ。
- 画面に映る体の大きさの補正はかけない。
- 「行動特徴は一般に課題依存」「課題プールは常に有害」とは書かない。
- 実験3で \(H_0:\rho_A=\rho_B\) を棄却した、とは書かない。
- 実験1・2・3を独立な追試のように書かない。同一の59人。実験3は実験1の当たりに条件づく。

情報源（子ども／検査者／二人）はセルの中では固定する。見るのは課題の切り分けである。

## 2. Spearman の \(\rho\)

どの実験も、人と得点の関係の主指標は Spearman の \(\rho\) である。

人 \(i=1,\ldots,n\) について、特徴の値 \(x_i\) と得点 \(y_i\) があるとする。非有限の組は捨てる。残った \(n\) 人で、平均順位法の順位 \(R(x)_i\)、\(R(y)_i\) を付ける。同じ値は、それらが占める順位の平均を与える。平均を引いたベクトルを \(u\)、\(v\) とする。

\[
\rho=\frac{\sum_i u_i v_i}{\sqrt{\bigl(\sum_i u_i^2\bigr)\bigl(\sum_i v_i^2\bigr)}}.
\]

これは順位の Pearson 相関である。分母が 0 なら出さない。\(n<3\)（実験1の列は \(n<8\)、実験2・3の一部は \(n<12\)）も出さない。

\(\rho>0\) は「特徴が大きい人ほど得点が大きい」。\(\rho<0\) はその逆。検査者の発話が多いほど SA が低い、などは後者である。

コード: `src/ados_ffm/exp1_univariate.py` の `spearman_rho_fast`。

## 3. 名札の入れ替えによる \(p\) と Benjamini–Hochberg

### 3.1 \(p\) を 0 にしない

帰無は「特徴とその人の点数の対応が無い」である。点数の名札だけを人単位で入れ替え、同じ統計量 \(\hat\theta\) を \(B\) 回出す。観測を \(\hat\theta_{\mathrm{obs}}\) とする。

両側（実験1）:

\[
p=\frac{1+\#\{\,b:\lvert\hat\theta_b^*\rvert\ge\lvert\hat\theta_{\mathrm{obs}}\rvert\,\}}{1+B}.
\]

片側・大きい方（実験2の LOPO）:

\[
p=\frac{1+\#\{\,b:\hat\theta_b^*\ge\hat\theta_{\mathrm{obs}}\,\}}{1+B}.
\]

分子の 1 は、観測自身を帰無の1点に数える補正である。\(B\) 回すべてが観測より小さくても \(p=1/(1+B)\) であり、0 にはならない。実験1は \(B=1000\)（下限 \(1/1001\)）。実験2は \(B=200\)（下限 \(1/201\)）。

### 3.2 Benjamini–Hochberg の \(q\)

同じ問いを \(m\) 本同時に見るとき、偽陽性の割合を抑える。\(p\) を小さい順に \(p_{(1)}\le\cdots\le p_{(m)}\) と並べ、

\[
\tilde q_{(i)}=\frac{m}{i}\,p_{(i)}
\]

を出す。大きい \(i\) から順に、右隣より大きくならないように切り、\([0,1]\) に収める。

\[
q_{(m)}=\min\bigl(1,\tilde q_{(m)}\bigr),\qquad
q_{(i)}=\min\bigl(q_{(i+1)},\tilde q_{(i)}\bigr)\quad(i=m-1,\ldots,1).
\]

元の順番に戻した \(q\) が各本の FDR 調整値である。\(q<0.05\) を、その範囲での当たりとする。コード: `src/ados_ffm/metrics.py` の `bh_fdr`。

範囲（家族）は数字を見る前に決める。

| 実験 | 家族 | \(m\) の中身 |
|---|---|---|
| 1 | 課題 × 得点 | その範囲の候補数 |
| 2 | 課題 × 得点 | その課題・得点で実際に回った情報源の数（最大3） |
| 3 | 使わない | CSV に \(q\) は残るが結果にしない |

実験1の候補までと実験2のセルを1つの家族に混ぜない。欠測で回らなかった本は \(m\) に入れない。BH の表には \(m\) を書く。

## 5. 実験1：1本ずつ

出力: `outputs/exp1/`。入口: `scripts/run_exp1_univariate.py`。実装: `src/ados_ffm/exp1_univariate.py`。

### 5.1 問い

特定の課題では、特定の情報源の特定の1本が点数と安定して共変する。効く1本は課題で違う。

### 5.2 使う列

その1本が測れている人だけ使う。同じ情報源の他の列が欠けていてもよい。人数が8人未満、または分散0の列は見ない。

### 5.3 ステージA（ここでは \(p\) を出さない）

対象は（課題, 情報源, 得点, 特徴1本）。

1. 測れている人を、重ならない半分に割る（人数 \(n\) のとき各 \(n//2\) 人。片側が5人未満なら安定度は出さない）。
2. 半分それぞれで Spearman \(\rho\) を出す。
3. **同じ符号**かつ **両方 \(\lvert\rho\rvert\ge 0.20\)** なら1点。
4. 分け方を200回繰り返し、点が付いた割合を安定度 \(S\) とする。

\(S\) は相関の強さではない。「半分に割っても、両方で同じ向きの関係が見える頻度」である。符号は正でも負でもよい（`positive_only=False`）。

### 5.4 安定度の閾値 \(\tau\)（本物の \(S\) を見る前にファイルへ書く）

課題×得点ごとに1本決める。情報源では共有する。

1. その課題の、その得点の名札だけを人単位で入れ替える。
2. 全特徴について、ステージAと同じ \(S\) を出す。
3. 入れ替えを50回繰り返す。
4. 大きい側5%（95パーセンタイル）を \(\tau\) にする。
5. `outputs/exp1/thresholds.json` に書いてから、本物の \(S\) を計算する。

人数が少ない課題ほど、偶然でも半分が当たりやすく、\(\tau\) は高い。

**候補**: 本物の \(S\ge\tau\)。\(\rho\) の符号は問わない。

### 5.5 ステージB（候補だけ、名札を入れ替える）

1. 候補の各1本について、全員の \(\rho\) を出す。特徴はその人のまま、点数の名札だけ1000回入れ替える。
2. \(p\) は両側（\(\lvert\rho\rvert\)）。
3. BH は **課題×得点**（例: おやつ×SA の候補だけが1範囲）。各範囲の候補数 \(m\) を残す。

当たり: \(q<0.05\)。

### 5.6 現行の結果（2026-08-28 の表）

| 項目 | 数 |
|---|---:|
| ステージA | 2010 |
| 候補 | 119 |
| FDR 当たり | **85** |
| 正の \(\rho\) / 負の \(\rho\) | 42 / 43 |
| ASR 依存の当たり | 12 |
| 当たりがある課題×情報源×得点セル | 41 |
| 同一課題×情報源×特徴が2得点に出る | 24（3得点は0） |
| ユニークな課題×情報源×特徴 | 61 |

課題5（絵）は当たり0。点数のまたぎは `scripts/run_exp1_target_overlap.py` → `outputs/exp1/target_overlap_*.csv`。`scripts/plot_exp1_hits.py` がセルごとの上位を `top5_per_cell.csv` に書く。

乱数の種: 安定度 41001、帰無 \(\tau\) 42001、置換 43001。

## 6. 実験2（本線）：学習側で1本選び、1人抜きする

実験1との違いは、**評価する人を学習から外し、その人の特徴を学習側だけで選ぶ**ことである。同じ59人なので、別の子どもたちでの確認にはならない。

入口: `scripts/run_exp2.py`。実装: `src/ados_ffm/exp2.py`。出力: `outputs/exp2/`。

### 6.1 どの条件を回すか

実験1で当たりが1本以上ある条件（課題×情報源×得点）だけ回す。41セル。特徴の候補は、その情報源のカタログ全部である（実験1の当たり列に固定しない）。

### 6.2 1人抜き

各人 \(i\) を1人ずつ外す（LOPO）。残った人だけで:

1. 実験1と同じステージA（安定度 \(S\ge\tau\)）。\(\tau\) は実験1で全標本に対してロックした値。LOPO 内では再計算しない。繰り返しは40回（実験1の200より粗い）。
2. 通過した列のうち、訓練の Spearman \(\lvert\rho\rvert\) が最大の1本を取る。通過0本なら \(\lvert\rho\rvert\) 最大に落とす。
3. 外した人の予測は \(\mathrm{sign}(\text{訓練}\rho)\times x_i\)。その列が欠測なら、その fold は予測しない。Ridge は使わない。列の標準化もしない。
4. 予測が有限な人について、予測と点数の Spearman がセルの \(\rho\)。

\(p\) は、点数の名札を人単位で入れ替えた LOPO の \(\rho\) が、本物以上になる割合（片側）。入れ替えのたびに学習側の列選びをやり直す。\(B=200\)。種の基点 77001。

画面に映る体の大きさの補正はかけない。

### 6.3 検定

BH は **課題×得点**。その課題・その得点で実際に回った情報源の \(p\) だけが入る。\(m\) は最大3。情報源が1つしか回らなければ \(m=1\)。

### 6.4 現行の結果

| 項目 | 値 |
|---|---:|
| セル | 41 |
| FDR 通過 | **2 / 41** |
| 平均 \(\rho\) / 中央 \(\rho\) | 0.297 / 0.323 |
| \(\rho>0\) | 40 / 41 |

通過: 自由遊び×検査者×SA（\(\rho=0.445\)、最多 `txt_examiner_n_utt`）、おやつ×検査者×SA（\(\rho=0.402\)、最多 `examiner_turn_words_mean`）。どちらも検査者×SA。子どもの特性の直接測定としては書かない。

限界: \(\tau\) は全 y でロックしている。置換200回なので \(p\) の粒度は \(1/201\)。通過2本を独立確認とは書かない。

## 7. 実験2の補助：実験1の当たりをそのまま Ridge

本線ではない。実験1で残った1本または2本を、fold 内で選び直さず Ridge に入れる。入口: `scripts/run_exp2_ridge.py`。出力: `outputs/exp2_ridge/`。

| 実験1の当たり | 補助で使う列 |
|---|---|
| 0本 | 回さない |
| 1本 | その1本 |
| 2本以上 | 上位2本 |

上位の並べは、\(q\) が小さい順、同じなら \(\rho\) が大きい順、同じなら安定度が大きい順、同じなら列名の辞書順。学習側だけで平均0・分散1にし、RidgeCV が \(\alpha\) を選ぶ（\(\alpha=10^{-1}\) から \(10^{4}\) まで30点）。fold 数は \(n\) に合わせる（\(n\ge40\) なら 5×10 など）。層は得点分位。BH の切り方は本線と同じ（課題×得点）。置換は1000回、片側。列選びは入れ替えに含めない。

現行: 41セル、FDR 通過 **37 / 41**。使う列がすでに実験1で選ばれているため通りやすい。実験2本線と同じ強さの確認としては書かない。

旧い移植・プールの近い／遠いは、この補助の FDR から切った。いまの実験3とは別である。

## 8. 実験3：同じ名前の特徴を課題のあいだで平均する

正本（仮定・順位の定義・平均したあとの式の導出・何が分かったか）: [`outputs/hetero/実験3_数式と手続き.md`](../outputs/hetero/実験3_数式と手続き.md)。共有 HTML: `outputs/sharing/exp3.html`。

入口: `scripts/run_hetero.py` と `scripts/run_exp3_findings.py`。出力: `outputs/hetero/`。

**仮定。** 59人は実験1と同じ。重症度は人に1本。一緒に動くかは順位に直したあとの \(\rho\)。プールは2課題の順位の平均。両方で有限な人だけを使う。21対は実験1の当たりから切る。差が0かの検定は結果にしない。10課題が同じ特性を測っている、とは置かない。

**操作。** (A) 67特徴×45課題対=3015で、重症度を使わず \(r=\rho(x_A,x_B)\)。(B) 順位平均 \(z=(R(x_A)+R(x_B))/2\) について \(\rho_z=(\rho_A+\rho_B)/\sqrt{2(1+r)}\) を実測と突き合わせる。(C) 21対の \(\rho_A,\rho_B\) と区間。(D) 鎖を検査者開始／子ども開始に分ける。(E) 区間長で符号が消えるかを見る。

**結果。** \(r\) の中央 0.25。その位置では弱い課題が強い課題の約 58% を残していないと、平均は強い課題より損。無害な課題を1つ混ぜると \(r=0\) なら約 29% 減る。符号が逆の組がある（21対のうち8）。測り損ないだけでは符号は安定して逆にならない。平均すると点だけが0へ動き、区間は狭まらない。反転は検査者開始の長い鎖の側にある。長さだけでは符号は消えない。

21対の切り方が差の大きい組を残すので、検定はしない。全セルの \(\lambda<\lambda^*\) が 81% という集計も、名札入れ替えの中央 82% と区別できないので使わない。

図の微修正は `exp3_findings.py` / `hetero.py`。\(\lambda\) シャッフルを省略するなら `--n-perm-lambda 0`。種: 対 89001、\(\rho_z\) 90001、\(Q\) 88001、\(\lambda\) シャッフル 92001、開始者 91001。

## 11. 用語

| 言葉 | 意味 |
|---|---|
| 情報源 | 子ども / 検査者 / 二人。特徴の所属 |
| 条件 / セル | 課題 × 情報源 × 得点 |
| 安定度 \(S\) | 半分割り200回（実験2では40回）のうち、両方同符号かつ \(\lvert\rho\rvert\ge 0.20\) だった割合 |
| 候補 | \(S\ge\tau\)（実験1） |
| 当たり（実験1） | 課題×得点の BH で \(q<0.05\) |
| 交差標本 | 2課題の両方でその特徴が有限な人 |
| \(r\) | 同名特徴の課題間 Spearman。点数を使わない |
| \(\rho_z\) | 順位平均プールと \(R(y)\) の Pearson |
| \(\lambda\) | 向きをそろえた \(\rho_B/\rho_A\)。\(\lvert\rho_A\rvert\ge\lvert\rho_B\rvert\)、\(\rho_A>0\) |
| \(\lambda^*(r)\) | プールが強い課題より得するための \(\lambda\) の下限 \(\sqrt{2(1+r)}-1\) |
| \(m\) | その BH 家族に入った本数 |
